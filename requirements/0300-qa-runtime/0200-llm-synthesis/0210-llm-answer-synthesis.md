# 0210 Agent Tool Loop and Answer Synthesis

[Requirements Home](../../0000-README.md) | [Area Overview](../0000-high-level-requirements.md)

## User Story

As a site visitor on a capable device, I can click "Ask" (or press
Shift+Enter) after a search and get a streamed, cited answer grounded in
this site's content, generated by a small model running entirely in my
browser.

## Key Fields/Parameters

- runtime: [WebLLM](https://github.com/mlc-ai/web-llm) `@mlc-ai/web-llm`, loaded on demand in a module worker (`eddie-agent-worker.js`), never on page load
- model: `data-agent-model="auto"` (default) picks `Qwen3.5-0.8B`; `"quality"` picks `Qwen3.5-2B`; any other value is passed through as a literal WebLLM model id. Variant suffix is `q4f16_1` when the adapter has `shader-f16`, else `q4f32_1`
- consent: an explicit click that states the download size, required before the first fetch of any agent model; the choice persists in `localStorage` (`eddie.agent.consent`)
- tool loop (bounded to 4 tool calls total, JSON-schema constrained via `response_format`):
  1. `plan`: `{ "queries": [..≤3], "need_page": null | url }`
  2. the widget executes `search` per query (hybrid mode, top 6, deduplicated) and, if requested, `page(url)`
  3. `decide`: `{ "action": "answer" | "search" | "read", "arg": "..." }` (at most one more round)
  4. `answer`: streamed text; the system prompt requires `[n]` citations mapping to the evidence list; a `<think>...</think>` block, if present, is stripped from the visible output
- when the evidence list is empty, the agent answers that the site doesn't cover the question rather than guessing

## Acceptance Criteria

- The agent model downloads only after consent and only on first Ask use, never on page load or on search alone.
- Download progress is shown with percentage and size, using the same download-progress UI as the search model (see [0320 Model Download Consent](../../0400-widget-ui/0300-download-progress/0320-download-consent.md)).
- The answer is streamed token-by-token as the model generates it, with a stop button that aborts generation.
- Every claim in the answer that draws on retrieved evidence carries a `[n]` citation resolvable to a source in the sources list; when there is no supporting evidence, the agent says so instead of fabricating an answer.
- The tool loop never exceeds 4 tool calls; if the model doesn't converge to an `answer` action within that budget, the agent answers with whatever evidence it has gathered rather than looping indefinitely.
- A new query while a previous answer is still streaming aborts that generation before starting the new one.
- No native Rust/WASM changes are required for the agent itself; it calls the existing `search`/`page` WASM exports as tools.
