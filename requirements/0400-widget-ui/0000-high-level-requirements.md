# 0400 High-Level Requirements — Widget UI

[Requirements Home](../0000-README.md)

A lightweight JavaScript widget that site owners embed via a `<script>`
tag (or a Hugo Module partial). Renders as a floating search button that
expands into a modal with type-ahead hybrid search results, an optional
inline retrieval-based answer blend, and an optional in-browser agent.
